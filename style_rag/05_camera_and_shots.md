# 05 — Camera & shot vocabulary

The reference behaves like a **live-action camera**: it has a lens (focus + DOF), it moves with
inertia (ease-in/out), and it frames for emotion. Observed shot types with examples:

| Code | Shot | Reference example | Use |
|---|---|---|---|
| EWS | extreme wide establishing, tiny characters | café façade 0:00, street 1:57 | open a location |
| WS | wide | lab 0:45, gym 2:15 | show geography |
| MS | medium / waist-up | barista hand-off 0:03 | dialogue |
| CU | head fills frame | 2:24 big eyes | reaction |
| ECU | eyes / hands / object macro | hand catching mug 0:15 | detail, proof |
| OTS | over-the-shoulder, blurred FG head | 1:54, 6:24 | conversation |
| LOW | low angle looking up | cup falling 0:12 | drama, slow-mo |
| TOP | top-down / bird's-eye | café table 0:21, ping-pong 2:21 | geometry, beat change |
| POV | character's view, hands in frame | 6:45 hands holding ball | immersion |
| INSERT | graphic/data insert | 0:51 chalkboard diagram | explanation |
| TRACK | side-tracking walk | 1:12–1:30 street walk | travel |

## Moves (always eased, never linear)
- **Slow push-in** (scale 1.00 → 1.08 over a shot) — default for any held shot.
- **Parallax slide** (layers move at different rates) for walks and reveals.
- **Rack focus** between FG and BG subject (blur swap) on a beat.
- **Snap zoom / punch-in** on comedic or shocking beats (4–6 frames).
- **Orbit** (simulate with parallax + rotation ≤ 4°) — reserve for the overload climax.
- **Dutch tilt** (≤ 6°) for unease.
- Micro **handheld drift** (±2 px, slow noise) on emotional close-ups.

## Framing rules
- Rule of thirds; eyes on the upper third line in CU.
- Look-room in the direction a character faces.
- Two-shots keep characters on opposite thirds; **distance between them = emotional distance**.
- Every shot has a blurred FG element OR a strong DOF fall-off.
- Never centre-frame a dialogue shot unless it is symmetrical on purpose (bathroom, courtyard).
