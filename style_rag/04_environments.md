## Construction (2.5D layer stack, back → front)
1. **Sky**: vertical gradient + sun disc with soft glow + god-ray fan + thin wispy cloud bands
   (long horizontal rounded strips, lighter on the underside).
2. **Far layer**: city skyline / tree line silhouettes, faded toward sky colour.
3. **Mid layer (set)**: the main architecture. Grid windows glowing amber, mullions dark.
4. **Ground**: street / floor plane with a subtle perspective gradient and a few lines.
5. **Subject layer**: characters + props they touch.
6. **Foreground**: out-of-focus silhouettes (railing, plant, another character's head/shoulder).
Each layer gets its own parallax factor (sky 0.05, far 0.2, mid 0.6, subject 1.0, FG 1.4) and its
own blur according to the focus distance.

## Recurring set dressing
- Windows: 2×2 or 3×4 panes, warm gradient brighter at top, occasional silhouette inside.
- Striped awnings with scalloped edge; hanging pendant lamps with light cones.
- Street lamps (thin pole + curved head + glow), lollipop trees, railings, steps, planters.
- Interior: wall gradient, a horizontal wainscot band, posters/frames as simple rectangles,
  wall clock, desks as trapezoids, light cones from windows across the floor.
