# 10 — The visual language of "seeing 5 seconds ahead"

The audience must learn this system in the first 60 seconds and never be confused afterwards.

## The three rules of the power (from the script)
1. When Leo concentrates, he sees a 5-second preview of what will happen **if nothing changes**.
2. If he changes an action, the old preview is void and a **new** preview can appear.
3. He sees only 5 seconds ahead — never long-term consequences.

## Visual system
| Element | Present (reality) | Future preview |
|---|---|---|
| Colour | Natural scene palette | Whole frame tinted deep blue `#0a1a3a`, desaturated |
| Characters/objects in the vision | Normal black + colour clothing | Translucent cyan ghosts `#7fc8ff` @ 45–55 % with an ice-white edge glow |
| Ghost inside the present | — | When a preview is shown *inside* a present-day frame (e.g. glass falling), only the ghost object is blue; the real object stays normal |
| Frame | Normal letterbox | Thin blue rounded border + `+5 s` label, faint scanline shimmer |
| Entry | — | Blue ring passes over Leo's pupils → frame flash → tint |
| Exit | — | Shards + reverse whoosh, or ghost dissolves upward like smoke |
| Sound | Normal | Muffled ambience, high ring, echoey ghost dialogue |

## Continuity rules
- Ghost and real versions of the same object must start from the **identical position** so the viewer sees they are the same thing.
- Present and future versions of a shot use **the exact same camera** (camera-match), so differences are obvious.
- In the climax, the corner countdown keeps ticking in the present while previews A → B → C replace each other.
- Leo only ever sees ~5 s ahead; never show a preview that goes beyond that.
